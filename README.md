# 周期提醒看板（免费云端版）

GitHub Pages仅发布此目录的静态代码。真实任务由用户登录后导入Supabase，代码仓库不包含业务数据。公开publishable key不是管理员密钥；数据库和Storage必须启用schema.sql中的按auth.uid隔离规则。

Supabase后台账号与应用Auth账号独立。打开网页后使用自己的邮箱注册应用账号，验证邮件后登录。每个账号只能访问自己的数据，不存在共享全局任务。

功能：固定编号、状态更新、周期分类、搜索、备注、HTTPS链接、私有文档上传/下载、JSON备份及首次导入。并发保存使用version条件更新，冲突时拒绝覆盖并提示刷新。

当前云端与本地知识库未自动双向同步；Codex定时提醒仍读取本地知识库。首次使用可从本地看板导出JSON后在云端登录导入，文档原件不包含在JSON中，需要重新上传。不要把整份飞书消息知识库加入此仓库。

免费服务额度以Supabase官方政策为准，闲置项目可能暂停，无自动升级或付费服务配置。定期自行导出备份。

安全：未登录无任务表权限，登录后按用户ID隔离；存储桶为私有，下载地址限时60秒；不永久删除文档。用户登录token保存在当前浏览器本地存储，公共电脑使用后退出登录。禁止把service_role/secret/数据库密码加入任何前端文件。
